# Tisam Parser

Telegram-бот для поиска организаций на Яндекс.Картах и в 2GIS. Собирает доступные контакты и отзывы, выделяет повторяющиеся жалобы и готовит черновик предложения по ним.

Анализ работает по правилам и ключевым словам. Результат стоит проверить вручную перед обращением к компании.

## Запуск

Нужен Node.js 22.12+:

```bash
npm ci
npx playwright install chromium
cp .env.example .env
```

Укажи `TELEGRAM_TOKEN` своего бота в `.env`, затем запусти:

```bash
npm start
```

В Telegram отправь боту, например:

```text
/parse стоматология
```

По умолчанию поиск идёт по Москве. Список городов задаётся в `bot/bot.js` в массиве `cities`.

## Настройки

Все переменные перечислены в `.env.example`. Основные:

| Переменная | Что меняет |
| --- | --- |
| `MIN_RATING`, `MAX_RATING` | Диапазон рейтинга организаций |
| `MIN_TOTAL_REVIEWS` | Минимальное число отзывов |
| `MIN_PAIN_SCORE` | Порог совпадений с темами жалоб; `0` отключает этот фильтр |
| `MAX_LEADS` | Максимальное число результатов |
| `FAST_PARSE` | Ускоренный режим ожиданий и прокрутки |
| `SKIP_CONTACTS_TAB` | Пропуск отдельной вкладки контактов |
| `SKIP_2GIS` | Поиск только на Яндекс.Картах |
| `HEADLESS` | Запуск браузера без окна |
| `PROXY_URL` | Прокси для браузера |
| `TELEGRAM_PROXY_URL` | Прокси для Telegram |

## Структура

- `bot/` - команды Telegram и сбор итоговой выдачи.
- `parser/` - работа с картами через Playwright.
- `analyzer/` - разбор отзывов и черновик предложения.
- `utils/` - ссылки, очистка текста и оформление результатов.

Для работы нужен доступ к Telegram и сервисам карт. Результат зависит от их доступности, текущей вёрстки и количества открытых отзывов. Файл `.env` с токеном исключён из Git.
